## 🚀 **How to Run & See the UI**

### Option 1: React Native (Recommended)
```bash
# Navigate to mobile directory
cd C:\Projects\govt-road-assist\road-assist\mobile

# Install dependencies
npm install

# Start Metro bundler
npx react-native start

# Run on Android
npx react-native run-android

# Or run on iOS (Mac only)
npx react-native run-ios
```

### Option 2: Expo (Alternative)
```bash
# Install Expo CLI globally
npm install -g @expo/cli

# Initialize Expo in mobile folder
expo init --template blank-typescript

# Copy our screens and components
# Start Expo
expo start
```

### Option 3: Web Preview (Quick Demo)
```bash
# Install React Native Web dependencies
npm install react-native-web react-scripts

# Start web version
npm run web
```
